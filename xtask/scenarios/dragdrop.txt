# Saved with the keybinding rather than the check on the bar. The check sits to
# the left of the run button, so its x moves with the width of the connection
# name beside it — a coordinate that changes when the environment is renamed is
# a coordinate that will be wrong again. Until it is saved the sidebar's row is
# a request with no target stored, and dropping one of those is what the drop
# refuses.
